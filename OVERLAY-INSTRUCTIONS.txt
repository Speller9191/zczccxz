Sandboxie-Plus local portable build — corrected NtCRT overlay

1. Extract this archive into the ROOT of your existing Sandboxie fork, merging
   folders and overwriting the included files.
2. From the repository root, run:

   git add .gitignore .github/workflows/main.yml LOCAL-BUILD.md
   git add Installer/PORTABLE-README.txt Sandboxie/core/drv/verify.c
   git add Sandboxie/core/drv/local_build_config.h
   git add Sandboxie/common/NtCRT/
   git status --short
   git commit -m "Fix NtCRT source tracking for all architectures"
   git push

The NtCRT directory in this overlay includes all checked-in .def/.obj linker
inputs referenced by Sandboxie/core/dll/SboxDll.vcxproj (Win32, x64, ARM64,
and ARM64EC). The updated .gitignore explicitly unignores these inputs even
though Visual Studio's generic rules ignore x86/, x64/, and *.obj.

The workflow preflight verifies the entire set before starting MSBuild. This
is a source-tracking/CI correction; it does not itself run MSVC/WDK or sign the
kernel driver. Review LOCAL-BUILD.md and the repository license files before
using or distributing the resulting binaries.
